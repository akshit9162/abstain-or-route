Route it, or hand it off.

Intent routing across 10 languages, with LoRA written from scratch.

Read the code The findings

Four findings

  1. LoRA ties full fine-tuning on a narrow target

    Trained on English, the mean gap is +0.2 points [−0.2, +0.6]. Across ten languages, rank 8 trails by 3.0.

  2. English-only training fails where pretraining is thin

    Swahili falls to 23.8% and Tamil to 47.9%. The same budget over ten languages lifts them to 58.7% and 73.3%.

  3. Calibration breaks in the same languages

    Expected calibration error for Tamil is 0.120 after English-only training, 0.028 after multilingual.

  4. Handing off cannot rescue an unknown language

    Deferring the least-confident 20% buys Hindi 10 points and Swahili 4.

Limits

  • One seed per run. The confidence intervals cover test sampling, not training variance.
  • Full fine-tuning froze the word embeddings: 96M of 118M parameters.
  • One LoRA configuration; no rank sweep.
  • Why Swahili is weakest is untested.

Reproduce

Saved logits in results/ rebuild every table in seconds.

git clone https://github.com/akshit9162/abstain-or-route
cd abstain-or-route
python -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -m src.evaluate   # every table
.venv/bin/pytest                   # 12 after setup
PATH=.venv/bin:$PATH ./setup.sh    # data and encoder
rm results/*/meta.json && ./run.sh # ~2 h on an M2
